# --- Number-plate OCR backends -------------------------------------------
# Pick one with `plate.ocr_backend` in config.yaml (or --ocr-backend). Vehicle
# counting works with none of these installed; plate reading just stays empty
# and says so. Character error rate on samples/plate_gt.csv, lower is better
# (n=5, so the ordering is solid and the values indicative):
#
#   paddle_anpr  CER 0.19   50ms   the DEFAULT - see the note at the bottom
#   fast_plate   CER 0.54    8ms   installed below
#   rapidocr     CER 0.88   370ms  installed below, fallback only
#
# "fast_plate": plate-specialised CCT model, small and fast (~5MB ONNX).
fast-plate-ocr[onnx]
#
# "rapidocr": generic scene-text OCR, not plate-specialised. Fallback only.
rapidocr-onnxruntime<2   # <2 matters: 2.x renamed the package and changed its return type
#
# ---------------------------------------------------------------------------
# HEADS UP: the DEFAULT backend is NOT installed by this file.
#
# plate.ocr_backend defaults to "fast_plate", which this file DOES install, so
# plate reading works on a clean `pip install -r requirements.txt`.
#
# It used to default to "paddle_anpr", which is more accurate (CER 0.19 vs
# 0.54) but needs three things pip cannot provide - a paddle wheel, ~150MB of
# weights, and a PaddleOCR source checkout that ppocr is imported from. The
# result was that a clean install read NO plates, announcing itself only as:
#
#   [plate] paddle_anpr unavailable: PaddleOCR checkout not found.
#
# That is graceful - detection, tracking, counting, lanes and congestion all
# still run - but it also meant no plate-keyed re-identification, and on the
# dashboard it looked like an empty column rather than a missing dependency.
# Hence the swap. To use the more accurate backend, complete the install:
#
#   pip install paddlepaddle safetensors scikit-image
#   mkdir -p models/anpr_ocr && cd models/anpr_ocr
#   curl -LO https://huggingface.co/Awiros/anpr-ocr/resolve/main/model.safetensors
#   curl -LO https://huggingface.co/Awiros/anpr-ocr/resolve/main/en_dict.txt
#   cd ../.. && git clone --depth 1 \
#       https://github.com/PaddlePaddle/PaddleOCR.git models/PaddleOCR
#
# ...then set plate.ocr_backend: "paddle_anpr" in config.yaml. `/cameras`
# reports which backend actually loaded, and the dashboard banners a failure.
#
# ...or switch to a backend this file does install:
#
#   python main.py --ocr-backend fast_plate
